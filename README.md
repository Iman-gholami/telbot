# 🌸 نرگس کوچولو — Telegram Bot

ربات فارسی بامزه برای گروه دوستانه؛ با شخصیت شیطون، صمیمی و طعنه‌زن.

## رفتار ربات

- شما را با عنوان **مهندس** می‌شناسد.
- دوست شما را با عنوان **خانوم دکتر** می‌شناسد.
- حدود ۸۰٪ مواقع در کل‌کل‌ها سمت مهندس است و حدود ۲۰٪ مواقع برای طبیعی‌تر شدن به مهندس هم تیکه می‌اندازد.
- حدود **۱ پیام از هر ۱۰ پیام** به‌صورت تصادفی وارد بحث می‌شود.
- اگر «نرگس» را صدا بزنید یا روی پیام خودش Reply کنید، حتماً جواب می‌دهد.
- ۱۰ پیام اخیر هر گروه را در حافظه موقت نگه می‌دارد تا جواب‌ها مرتبط باشند.
- بخشی از جواب‌ها آماده‌اند و بخشی با AI ساخته می‌شوند.
- اگر AI در دسترس نباشد، ربات با جواب‌های آماده به کار ادامه می‌دهد.

## نیازمندی‌ها

- Node.js 20 یا جدیدتر
- یک Telegram Bot Token از `@BotFather`
- یک OpenRouter API Key برای جواب‌های AI

مدل پیش‌فرض `openrouter/free` است تا از مدل‌های رایگان موجود در OpenRouter استفاده شود. رایگان بودن و محدودیت‌ها ممکن است در طول زمان تغییر کند.

## 1) ساخت ربات در Telegram

در تلگرام وارد `@BotFather` شوید و دستور زیر را بزنید:

```text
/newbot
```

اسم نمایشی را می‌توانید `نرگس کوچولو` بگذارید و یک username آزاد برایش انتخاب کنید.

### مهم: دریافت پیام‌های گروه

چون نرگس باید بدون صدا زدن هم گاهی وارد بحث شود، در BotFather این دستور را اجرا کنید:

```text
/setprivacy
```

ربات را انتخاب کنید و **Disable** را بزنید. سپس اگر ربات از قبل داخل گروه بوده، بهتر است یک‌بار آن را حذف و دوباره اضافه کنید.

## 2) نصب پروژه

```bash
git clone https://github.com/Iman-gholami/telbot.git
cd telbot
npm install
```

## 3) تنظیم متغیرهای محیطی

فایل نمونه را کپی کنید:

```bash
cp .env.example .env
```

داخل `.env` این مقادیر را تنظیم کنید:

```env
BOT_TOKEN=توکن_ربات_تلگرام
OPENROUTER_API_KEY=کلید_OpenRouter
AI_MODEL=openrouter/free

ENGINEER_ID=
DOCTOR_ID=

RESPONSE_RATE=0.10
FIXED_REPLY_RATE=0.35
MEMORY_SIZE=10
```

> هیچ‌وقت فایل `.env` یا کلیدهای واقعی را روی GitHub commit نکنید. `.env` از قبل در `.gitignore` قرار گرفته است.

## 4) پیدا کردن ID مهندس و خانوم دکتر

ابتدا می‌توانید ربات را با IDهای خالی اجرا کنید:

```bash
npm start
```

بعد شما و دوستتان هر کدام در تلگرام برای ربات یا داخل گروه دستور زیر را بزنید:

```text
/id
```

نرگس ID عددی هر نفر را برمی‌گرداند. سپس ربات را متوقف کنید و در `.env` قرار دهید:

```env
ENGINEER_ID=123456789
DOCTOR_ID=987654321
```

دوباره اجرا کنید:

```bash
npm start
```

## دستورها

- `/start` — معرفی کوتاه ربات
- `/id` — نمایش ID عددی شما و چت
- `/ping` — تست زنده بودن ربات
- `/narges` — اجبار نرگس به جواب دادن
- `/narges متن دلخواه` — گرفتن واکنش نرگس به یک متن مشخص

## شخصی‌سازی

در `.env`:

```env
RESPONSE_RATE=0.10
```

یعنی تقریباً ۱۰٪ پیام‌های معمولی؛ برای مثال `0.20` یعنی حدود ۲۰٪.

```env
FIXED_REPLY_RATE=0.35
```

یعنی حدود ۳۵٪ جواب‌ها از بانک جواب‌های آماده انتخاب می‌شوند و بقیه در صورت در دسترس بودن AI ساخته می‌شوند.

```env
MEMORY_SIZE=10
```

تعداد پیام‌های اخیر هر گروه که نرگس برای فهمیدن فضای بحث نگه می‌دارد.

## حافظه و حریم خصوصی

حافظه گفتگو فقط در RAM برنامه نگه داشته می‌شود و در دیتابیس ذخیره نمی‌شود. با restart شدن برنامه پاک می‌شود.

## اجرای توسعه

```bash
npm run dev
```

```bash
npm run check
```

## نکته درباره OpenRouter

اگر `OPENROUTER_API_KEY` تنظیم نشده باشد، یا درخواست AI خطا بدهد/سهمیه در دسترس نباشد، ربات از جواب‌های ثابت استفاده می‌کند و از کار نمی‌افتد.
